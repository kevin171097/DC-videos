# DC VIDEOS — proyecto inicial

Proyecto base de demostración para Android con Expo/React Native. Incluye una pantalla vertical de videos de muestra, navegación básica y botón de me gusta.

## Importante
Esta versión es una DEMO: todavía no permite registrar usuarios, subir videos reales, comentar, seguir cuentas, moderar contenido ni monetizar. No es un APK compilado.

## Preparación
1. Instalar Node.js y ejecutar `npm install`.
2. Para probar: `npx expo start`.
3. Para generar APK Android se requiere configurar EAS Build y ejecutar una compilación.

Paquete Android: `com.dcmodas.dcvideos`.
